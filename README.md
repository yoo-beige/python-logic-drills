# Python Logic Drills

This repository contains beginner-level Python programs focused on
building strong programming fundamentals and logical thinking.

The goal of this repository is not to showcase advanced projects,
but to demonstrate clear understanding of core concepts such as
conditions, loops, and number-based logic.

---

## Topics Covered
- Conditional statements
- Looping constructs (`for` loops)
- Number-based logical problems
- Basic problem-solving patterns

---

## Programs Added

### Basics
- Even or Odd check  
- Positive / Negative / Zero check  
- Maximum of two numbers  

### Loops
- Sum of numbers from 1 to n  
- Factorial calculation  

### Number Problems
- Prime number check
